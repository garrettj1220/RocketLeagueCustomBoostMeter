Setup steps

1
Open the Rocket League config folder
Documents\My Games\Rocket League\TAGame\Config
2
Open DefaultStatsAPI.ini
Create the file if it is missing.
3
Use port 49123
[TAGame.MatchStatsExporter_TA] Port=49123 PacketSendRate=10
4
Restart Rocket League
The app can stay open. It reconnects automatically.
5
Add the OBS browser source
Use the OBS URL from Overview. Width and height can be 1920 x 1080.
6
Rocket League Stats API docs
https://www.rocketleague.com/en/developer/stats-api
